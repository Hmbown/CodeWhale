# Dead-code inventory (compiler-verified)

Generated by stripping every `#[allow(dead_code)]` outside the
`config/src/route/` guardrail and recording what `cargo check --workspace
--all-targets --all-features` then reports. Unlike a grep or an
`allow`-attribute count, every entry here is an item rustc proved is
unreachable from any target, including tests.

**513 unique dead items across 139 files.**

By kind: methods 110, function 86, associated 70, method 61, fields 54, field 33, variants 29, constant 25, variant 15, struct 13, enum 8, multiple 8, trait 1

## How to use this

Dead code here forms **clusters**: `sync_one_skill` is reported dead because its
only caller is also dead. Deleting one member of a cluster while leaving the
rest does not compile — an attempt at exactly that produced 38 `cannot find`
errors. Delete a whole cluster at a time, or delete every item in a file and let
the compiler pull the thread.

Two hazards this list cannot see:

- **Platform-gated code.** This was generated on macOS, so anything referenced
  only from `cfg(windows)` blocks looks dead here and is not. Check before
  deleting.
- **The do-not-delete guardrail** in `AGENTS.md` (`context_budget.rs`,
  `model_registry.rs`, `prompt_zones.rs`, `tools/remember.rs`,
  `config/src/route/`). Those are live despite appearances.
