# Codewhale mark

Canonical mark: white side-view whale facing left, `>` prompt-eye cutout
(even-odd), small belly crease, upward fluke.

- `whale.svg` — silhouette only (`currentColor`). In-page chrome source.
- `tile-*.svg` — squircle tiles. `tile-electric.svg` (#0066FF) is the
  website app icon source (`web/app/icon.svg`).
- Rasters in `web/public/brand/` and `web/public/icon-{192,512}.png`.

Do not restore the symmetric fluke. At 16px that mark reads as a fish.
